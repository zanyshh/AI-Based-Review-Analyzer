# 🤖 ReviewGuardian AI

> An AI-powered fake review detection system that combines Machine Learning and Large Language Models (LLMs) to identify suspicious online reviews with explainable results.

## ✨ Features

- 🔍 Detects Fake & Genuine Reviews
- 🤖 Hybrid AI (Machine Learning + LLM)
- 📊 Logistic Regression & Random Forest Ensemble
- 🧠 Groq Llama 3.3-70B Semantic Analysis
- 📈 Confidence Score Prediction
- 💡 AI-Powered Explanation
- ⚡ Real-Time Review Analysis
- 🎨 Cyberpunk-Inspired Streamlit UI

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorizer
- Logistic Regression
- Random Forest
- Groq API
- Llama 3.3-70B
